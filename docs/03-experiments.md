# 实验设计

默认假设（老师未反对前）：

> 在一类产品的公开缺陷/损伤数据上，整图分类能分开 3 档损伤；  
> 「先定位损伤区域再分级」若提升有限或只在小划痕上有用，要把这个写进论文当结果，不是藏起来。

正确性：固定划分与随机种子；别人按 README 能复现表中数字。

---

## 1. 阶段

| 阶段 | 做什么 | 不要做什么 |
|------|--------|------------|
| 环境检查 | CIFAR 或小 ResNet，证明 GPU/CPU 能训几个 epoch | 此时不要下大数据集 |
| M1 | 公开集整图分类基线（Accuracy / 每档 F1） | 不要设计新模块 |
| M2 | ≥3 对照：例如 ImageNet 预训练线性探测 / 微调 ResNet / 一种有序损失或轻量增广 | 不要同时上 ViT 大模型和检测 |
| M3 | 失败案例图；可选 200–500 张真实自拍 | 不要因为校园图不够就停更 |
| M4 | 把表和图收进报告 | 不要为了数字去换测试集 |

老师若圈 **C（检测）**：M1 改为公开缺陷检测 mAP，分级当第二段。仍只做一条主输出。

---

## 2. 数据（由易到难）

1. **立刻：** 工业表面缺陷公开集（如 NEU、MVTec 改成有/无或按缺陷类型近似成档）。先能跑，再跟老师对齐「档怎么定义」。  
2. **老师若有旧数据：** 优先用，发文更好接他过往工作。  
3. **课设图：** 校园二手发布图；成色若自标，先 3 档、两人交叉标一小部分算一致率。

标注原则：档少、标准写死、先小后大。不自建「全品类损伤本体」。

数据放 `data/`，**不进 git**。在 `experiments/` 写：来源 URL、许可、划分脚本、类别定义。

---

## 3. 指标与陷阱

**先用：** Accuracy、macro-F1、混淆矩阵。有序误差（差一档 vs 差两档）有则更好。

**坑：**

- 只报训练准确率或测试泄漏  
- 无基线，只说「用了 ResNet 所以有效」  
- Mac 与 Y7000P 数字混为一谈  
- 同时开检测 + 检索 + CLIP  
- 为水文买版面

---

## 4. 机器约定

- **Y7000P：** 主训练。记 CPU/GPU、是否插电、CUDA 版本。  
- **Mac：** 脚本、可视化、CPU 过拟合一张图。256GB 不存原始大数据。  
- **AutoDL：** 仅 M2 需要更大 batch / 稍大骨干时按天租。

每次实验在 `experiments/YYYYMMDD_短名.md` 记录命令、超参、结果文件路径。CSV 进 `results/`。

---
