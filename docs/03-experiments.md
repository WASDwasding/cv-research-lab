# 实验设计

默认假设（未反对前）：

> 在一类产品的公开缺陷/损伤数据上，整图分类能分开 3 档损伤；  
> 「先定位损伤区域再分级」若提升有限或只在小划痕上有用，要把这个写进论文当结果，不是藏起来。

正确性：固定划分与随机种子；按 README 能复现表中数字。

---

## 1. 阶段

日历是 31 天，实验块不删。日期对应 `PLAN.md`。

| 阶段 | 日期 | 做什么 | 完成时要有的数字 |
|------|------|--------|------------------|
| 环境 + 规则 | 09-22～09-23 | 最小训练；选定 1 个带框或掩膜的公开集；3 档映射写死 | val 准确率；映射表 |
| 划分 + M1 | 09-24～09-28 | 固定种子；多数类；预训练微调两种子；混淆矩阵；有序误差 | test Accuracy、macro-F1、每档 F1、MAE、差一档、差两档 |
| 对照 + 消融 | 09-29～10-01、10-04 | 线性探测、有序损失、强增广或第二骨干；有序损失开/关；增广开/关 | 主表 ≥4 行；消融 ≥2 行 |
| 定位再分级 | 10-02～10-03 | 检测或分割后裁剪/遮罩，再分级；小/大尺度分组。有框或掩膜时报告 mAP@0.5 或 IoU | 与最佳整图同一测试集的分级指标 + 分组表 |
| 失败案例 | 10-06、10-09 | 全量错例分型；论文图版 ≥8 | 每型张数及占错误比例 |
| 真实小集 | 10-07～10-08 | ≥90 张，每档 ≥30；其中 ≥30 张双标 | 一致率、kappa、相对公开测试集的掉点 |
| 冻结 | 10-12 | 以上各表锁定 | 表头日期 2026-10-12 |
| 成文投稿 | 10-13～10-22 | 清单内所有表图进正文并投稿 | 回执 |

主输出仍是 3 档等级。定位是分级前面的对照，两套指标都要。不上 ViT 大模型，不并进检索或视频。10 月 12 日之后不换测试集。

## 2. 数据（由易到难）

1. **立刻：** 工业表面缺陷公开集（如 NEU、MVTec 改成有/无或按缺陷类型近似成档）。先能跑，再对齐「档怎么定义」。  
2. **已有标注数据：** 优先用，便于接过往工作。  
3. **真实拍摄图：** 若自标成色，先 3 档、两人交叉标一小部分算一致率。

标注原则：档少、标准写死、先小后大。不自建「全品类损伤本体」。

数据放 `data/`，**不进 git**。在 `experiments/` 写：来源 URL、许可、划分脚本、类别定义。

---

## 3. 指标与陷阱

**先用：** Accuracy、macro-F1、混淆矩阵。有序误差（差一档 vs 差两档）有则更好。

**坑：**

- 只报训练准确率或测试泄漏  
- 无基线，只说「用了 ResNet 所以有效」  
- 把不同机器上的数字合成同一张表  
- 同时开检测 + 检索 + CLIP  
- 为水文买版面

---

## 4. 机器约定

- **GPU 机器：** 主训练。记录 CPU/GPU、CUDA 版本。  
- **笔记本：** 脚本、可视化、CPU 冒烟。不存原始大数据集。  
- **云 GPU：** 仅 M2 需要更大 batch / 稍大骨干时按天租。

每次实验在 `experiments/YYYYMMDD_短名.md` 记录命令、超参、机器、结果文件路径。CSV 进 `results/`。文件名带日期和机器，例如 `20260928_m1_gpu.csv`。10 月 12 日冻结后，新文件只允许放图注和核对记录，不放新测试数字。
