# 研究方向：从图像评估产品损伤程度

> 给老师、同学、合作方看。  
> 英文：`damage / defect / wear severity estimation`。中文：成色评估、缺陷检测、损伤分级。  
> 来源：2026-09-15 从申请计划里的方向笔记收进本仓库。

---

## 1. 一句话

人看一张产品照片能判断「伤得重不重」。本课题让模型做同一件事：在**已经知道是哪类产品**的前提下，给出损伤档次，必要时标出伤在哪里。

生活对应：二手成色、工厂外观质检、保险外观预检。

---

## 2. 学科位置

| 别人问 | 怎么答 |
|--------|--------|
| 大方向 | 计算机视觉 |
| 应用方向 | 视觉质检 / 产品状态评估 |
| 默认任务 | 细粒度有序分类（3 档损伤） |
| 可选前置 | 缺陷检测或分割（框/涂出伤痕） |

不是「这是猫还是手机」，而是「这只手机现在伤成什么样」。

```
商品图
 ├── 这是什么？          → 分类（本课题不当主问题）
 ├── 是不是同一件？      → 检索（课题 A，非默认）
 ├── 东西在画面哪？      → 检测（课题 C，仅当前置）
 └── 伤得有多重、伤在哪？ → 本课题（默认 B）
```

---

## 3. 四种做法（只锁定一种主输出）

| 类型 | 输出 | 适合现在？ |
|------|------|------------|
| **1 等级（默认）** | 无 / 轻 / 中重 | ✅ 最好标、最好发 EI |
| 2 位置+程度 | 框/掩膜 + 等级 | 老师偏检测时再加 |
| 3 连续分数 | 0–10 | 标注主观，先不做 |
| 4 视频 | 多视角短视频 | 标注和训练都更重，先不做 |

档次有顺序：把「轻」预测成「中」应比预测成「严重」惩罚更小（有序分类）。

---

## 4. 本科收得住的题目

> 针对一类产品（如手机壳 / 包装 / 钢材表面公开集），用图像估计损伤等级。  
> 先在公开缺陷数据上复现整图分类基线，再比较「先找损伤区域再分级」是否更准。  
> 最后若有校园自拍，验证反光、脏背景时掉多少点，把失败案例写进论文。

不要写：「用 AI 分析所有产品在图片和视频中的各种损伤」。

---

## 5. 指标（论文至少要有）

- 等级：Accuracy、每档 F1、混淆矩阵；最好看有序误差  
- 若做检测：mAP@0.5  
- 必须有：**基线、≥3 对照、失败案例**（反光当划痕、小裂纹看漏、背景当伤）

---

## 6. 搜论文关键词

中文：产品成色评估、表面缺陷检测、损伤分级、外观质检。  
英文：`damage severity estimation`，`surface defect detection`，`wear assessment`，`ordinal classification`，`visual inspection`。

公开数据入口：MVTec AD、NEU 钢材表面、各类划痕/裂纹分割集。商品成色往往要自己标 3 档小集；可先用工业缺陷集把方法跑通。

---

## 7. 不是什么

不是通用识别、不是照片糊不糊的质量评价、不是生成修复图、不是医疗诊断、不是必须上视频和大模型。
