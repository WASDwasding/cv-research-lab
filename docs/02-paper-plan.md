## 1. 为什么是 EI，不是 SCI / CVPR

| 档 | 判断 |
|----|------|
| CVPR / ICCV / NeurIPS 一作 | 不作为当前目标 |
| SCI 一区 / CCF-A | 周期长、中稿难，不作为当前目标 |
| **正规 EI 会议或应用刊** | **当前目标**：页数短、应用向，接受特定场景 + 基线 + 对照 |
| 包录 / 假会 | 禁止 |

一篇合格 EI 仍然需要：问题清楚、相关工作、可复现实验、基线、对照、局限。英语短文（常见 4–6 页 IEEE 双栏）也要写。

## 2. 投稿原则

1. **圈定会/刊之前不投稿。**  
2. 优先能在 IEEE Xplore / SPIE / 期刊官网核到的出处。  
3. 录用后核：EI Compendex 是否真收录**该届**论文集，而不是官网写「提交 EI」。  
4. 不要为了赶 2026 年 10–11 月的会而在没有 M1 数字时投稿。第一篇瞄准 **2027 春夏会期或期刊**。

不要投「保证检索、三天录用」的中介会。

## 4. 文章骨架

1. **问题：** 特定产品外观损伤要稳定分级  
2. **相关工作：** 缺陷检测、有序分类、成色评估  
3. **方法：** 整图分类基线；可选「先分割/检测再分级」  
4. **实验：** 公开集；指标；对照；失败案例  
5. **局限：** 反光、跨产品泛化、标注主观性  

贡献不写「提出全新网络」，写「分级定义 + 对照 + 何时失效」。
