## 1. 为什么是 EI，不是 SCI / CVPR

| 档 | 判断 |
|----|------|
| CVPR / ICCV / NeurIPS 一作 | 不作为当前目标 |
| SCI 一区 / CCF-A | 周期长、中稿难，不作为当前目标 |
| **正规 EI 会议或应用刊** | **当前目标**：页数短、应用向，接受特定场景 + 基线 + 对照 |
| 包录 / 假会 | 禁止 |

一篇合格 EI 仍然需要：问题清楚、相关工作、可复现实验、基线、对照、局限。英语短文（常见 4–6 页 IEEE 双栏）也要写。

1. **圈定会/刊之前不投稿。**

4. **2026-10-22 前投稿，且必须带着 2026-10-12 已冻结的全部表。** 这 31 天交付完整文稿和投稿，不交付 EI 检索。正规会刊从录用到 Compendex 收录还要更久。  
5. 候选出处的截稿日不得早于 **2026-10-22**。来不及冻结数字的截稿放弃，不空投。  
6. 正文按 `PLAN.md` 第 1 节清单写全：引言、相关工作三节、方法三节、主表、定位臂、消融、有序误差、失败案例、真实小集、局限、结论、复现。模板页数不够时压缩句子，不删这些块。视频、连续分数、新网络不进入本稿。

## 4. 文章骨架

1. **问题：** 手机和平板屏幕外观损伤要稳定分成无 / 轻 / 中重  
2. **相关工作：** 缺陷检测、有序分类、成色评估  
3. **方法：** 3 档书面规则；整图分类与有序损失；先定位再分级  
4. **实验：** 公开集主表（多数类 + ≥3 个设置）；定位臂与尺度分组；消融；每档 F1、混淆矩阵、有序误差；失败案例；真实小集与一致率  
5. **局限：** 反光、手机屏到平板屏、标注主观性、SSGD 的缺陷类别映射不等于真实成色，且公开集缺少完好屏幕  

贡献写「分级定义 + 对照（含定位再分级）+ 何时失效」。定位臂提升有限时照写。不写「提出全新网络」。
