## 1. 为什么是 EI，不是 SCI / CVPR

| 档 | 判断 |
|----|------|
| CVPR / ICCV / NeurIPS 一作 | 不作为当前目标 |
| SCI 一区 / CCF-A | 周期长、中稿难，不作为当前目标 |

## 4. 文章骨架

1. **问题：** 手机和平板屏幕外观损伤要稳定分成无 / 轻 / 中重  
2. **相关工作：** 缺陷检测、有序分类、成色评估  
3. **方法：** 3 档书面规则；整图分类与有序损失；先定位再分级  
4. **实验：** 公开集主表（多数类 + ≥3 个设置）；定位臂与尺度分组；消融；每档 F1、混淆矩阵、有序误差；失败案例；真实小集与一致率  
5. **局限：** 反光、手机屏到平板屏、标注主观性、SSGD 的缺陷类别映射不等于真实成色，且公开集缺少完好屏幕  

贡献写「分级定义 + 对照（含定位再分级）+ 何时失效」。定位臂提升有限时照写。不写「提出全新网络」。
