# 计算机视觉：从暑期作业到世界模型

> 背景阅读，写于 2026-10-11。用来把本课题（手机和平板屏幕损伤分级）放回学科史里。  
> 不是实验结论，文中的历史数字不进论文主表。

计算机视觉的主线，是人一次次低估了「看」这件事。1966 年有人觉得一个夏天就能让计算机看懂世界；六十年后，机器已经能给照片起名、把伤痕圈出来、甚至按动作往前演一段世界，但在反光、脏背景、少见损伤这些具体场合里，它仍然会看错。

---

## 1. 一个夏天没做完的作业（1960s–1980s）

1966 年夏天，麻省理工学院的人工智能小组留了一份作业：给计算机接上摄像头，让它把看到的东西分成物体、背景和各自的关系。负责人以为，视觉只是人工智能里一个暑期项目。这份作业后来被称为夏季视觉项目（Summer Vision Project）。

那时的世界被简化成桌上的积木。劳伦斯·罗伯茨 1963 年的博士论文已经在做这件事：先找边缘，再把边缘连成线，再猜这些线围成的是方块还是楔形。这套办法在实验室的白桌子上能工作。灯一换、影子一多、东西一重叠，规则就断了。

1970 年代末，大卫·马尔把这件事说清楚了。他的《视觉》在 1982 年出版，把「看」拆成三层：先问计算上要解决什么问题（比如从二维图像恢复表面朝向），再问用什么算法，最后才是用什么硬件去实现。他设想了一条流水线：先画出边缘草图，再估计一张带深度的「二维半」草图，最后才拼出三维物体。这个框架影响了后面几十年。人们开始相信，视觉是可以分层、可以一步步算出来的。

同一时期，神经科学给了另一条线索。休伯尔和威泽尔发现，猫的视觉皮层里有的细胞只对特定方向的边缘起反应，后面的细胞再把这些简单反应组合成更复杂的形状。1980 年福岛邦彦按这个想法做了「新认知机」，它已经有了后来卷积神经网络的影子：一层层局部感受、一层层抽象。1998 年杨立昆的 LeNet 用同样的思路认手写数字，在支票识别里真的上了班。那时图像还小、数据还少、计算机也慢，这套网络出了实验室就推不远。

八十年代因此变成了手工规则的长跑。光流、立体视觉、从阴影恢复形状、1986 年的坎尼边缘检测，每一项都是扎实的算法。工厂里开始有了简单的视觉质检。系统很脆：换一条产线，往往得重新调一套参数。

## 2. 给图像按指纹（1990s–2010）

九十年代，人们换了一个信念：与其写死规则，不如让机器在大量例子里学统计规律。

给人脸做「特征脸」（Turk 与 Pentland，1991），是把一张脸看成高维空间里的一个点，用少数几个主方向去概括千变万化的五官。2001 年的 Viola–Jones 人脸检测更实际：用简单的明暗块当特征，用级联分类器把明显不是脸的窗口尽快扔掉。数码相机里那个方框追着脸跑，就是这一代工作走进了日用品。

真正改变「找东西」方式的是 1999 年大卫·洛的 SIFT（期刊版 2004）。它在图像里找一些对旋转、缩放、光照相对稳定的局部斑点，给每个斑点写一段描述，像指纹。两张从不同角度拍的同一栋楼，可以用这些指纹对上。后面十几年，HOG（2005）、词袋模型、可变形部件模型，都是这条路的延伸：人来设计「什么算一个好特征」，计算机负责在特征上做分类。

这条路在 2010 年前后走到了天花板。每年的 PASCAL VOC 竞赛里，检测行人、汽车、椅子的分数涨得越来越慢。特征是人设计的，设计空间被掏得差不多了。

## 3. 一本相册，和一次翻盘（2009–2017）

李飞飞在 2000 年代末做了一个当时看起来很笨的决定：与其再雕一个更巧的特征，不如先建一本巨大的相册。ImageNet 用众包给上千万张图打上一千个类别的标签。2009 年数据集发布，2010 年起每年办一次识别竞赛。头两年，最好的方法仍是那些手工特征，错误率下降很慢。

2012 年，亚历克斯·克里哲夫斯基、伊利亚·苏茨克维和杰弗里·辛顿交上了 AlexNet。它是一个更深的卷积神经网络，在两块显卡上训练，用整流激活、随机失活和大量数据增强。在 ImageNet 上，前五名错误率从大约 26% 掉到大约 15%。第二名还在用传统方法。差距大到会场安静了一下。

事后看，赢的是三件事同时到齐：够大的标注数据、够强的显卡，以及一个能把局部图案一层层叠成「边缘 → 纹理 → 部件 → 物体」的网络。福岛和杨立昆早年看见的那条路，终于有了燃料。

接下来三年像打开了闸门。网络越做越深，深到训练不动。何恺明等人 2015 年用残差连接让一百多层的 ResNet 训得起来，ImageNet 上的成绩越过了人在那个测试集上的水平。人们同时把「看」拆成几种不同的问题：

- **分类**：这张图整体是什么。
- **检测**：东西在哪，用框标出来。Faster R-CNN 先提议区域再识别；YOLO（2016）改成看一遍图就同时出框和类别，开始能实时跑。
- **分割**：哪些像素属于伤痕、道路或器官。全卷积网络和 2015 年的 U-Net 把「逐像素着色」做成了标准工具。医学和工业质检到今天还在用 U-Net 这一族。
- **生成**：2014 年的生成对抗网络让机器开始画出它见过的那类图像。

到 2017 年左右，一个默认印象形成了：互联网上常见物体的「认出来、框出来」，深度网络已经很强。Mask R-CNN 把检测和分割接到了同一个框架里。

## 4. 从背类别，到自己长出眼睛（2018–2023）

下一个转折是：模型不必再死记那一千个类名。

2020 年，Vision Transformer 把图切成小块，当成一串符号送进原来为语言设计的 Transformer。它在超大数据上工作得很好，说明「看」不一定要靠卷积那种固定的局部窗口，注意力也可以在整张图上决定该看哪一块。几乎同时，DETR 用 Transformer 把检测做成端到端：少了以往那套锚框和后处理的手工设计。

自监督学习也在这几年成熟了。与其只靠人工标签，不如让模型做填空和对照：把图遮住一块让它猜，或者让同一张图的两个裁剪在特征空间里靠近、不同图远离。何恺明的掩码自编码（MAE），以及 Meta 后来的 DINOv2，都沿着这条路做出了很能迁移的视觉特征。拿到一个小任务、标签只有几千张时，往往先拿这种特征当起点，而不是从零训一个网络。

2021 年的 CLIP 把图和句子配成对来训练。模型把图像和文字放进同一个空间。给它一句没在训练里出现过的话，它也能在一堆图里把意思对上。视觉从封闭的考卷里走出来，开始和语言绑在一起。

2023 年 Meta 的 SAM（Segment Anything）把分割也做成了可提示的基础模型：点一下、框一下，它就分出物体。训练用了约十亿个掩膜。工业和标注工具里，它很快变成了「先粗分、人再改」的默认起点。

同一阶段，三维也复活了。2020 年的 NeRF 用神经网络表示一个场景里每一点的颜色和密度，于是能从几张照片合成新视角。2023 年的 3D 高斯泼溅改用一堆半透明的椭球来表示场景，速度到了可交互。人终于比较省力地得到了「这间屋子的形状和外观」。

## 5. 现在最前沿在干什么（2024–2026）

2024 到 2026，顶会和工业实验室的注意力聚成了几条，而且它们在汇合。

**视觉成了大模型的一种感官。** 语言模型学会读图之后，问题从「这是猫吗」变成「这张屏幕上的裂纹严不严重、可能影响使用吗」。开放的视觉语言模型（包括 Qwen-VL、InternVL 这一类）已经能做看图问答、指代、简单推理。强在常识和表达，弱在稳定的刻度：同一条细划痕，换个角度、打个反光，回答会漂。

**生成模型在学「世界会怎么动」。** 扩散模型先学会画静帧，接着被推进视频。Sora，以及后来的可灵、混元、Wan、Veo 这一批系统，卖点都是：给出开头和动作，往后生成一段看起来连贯的影像。研究圈把这件事叫世界模型——机器内部有一个能往前推演的模拟器。2026 年的综述和 CVPR 讨论的重点已经很具体：动作怎么真正控制下一帧、时间一长会不会穿帮、能不能快到实时，以及评价时能不能少看「像不像照片」、多看「物理上站不站得住」。

**看，是为了动手。** 机器人方向的视觉–语言–动作模型，输入相机画面和一句指令，输出关节或夹爪的动作。CVPR 2026 上已有工作把动作和场景都放进三维点的流动里：看一眼真实环境里的深度图，预测物体会怎么被推走，并用这个预测去做控制。自动驾驶、家用机器人和游戏引擎在抢同一类能力：看见、预测、再行动。

**三维表示还在变瘦、变通用。** 高斯泼溅之后，目标从「一个场景训一个模型」变成：喂几张没有位姿的照片，就直接吐出紧凑的三维。有的工作用大约两千个高斯球概括一个房间。重建要能带着语义，让后面的机器人或编辑工具用得上。

这几条前沿共享一个判断：下一阶段的视觉系统要同时完成四件事——认、分、生成、预测动作后果。算力和数据的门槛因此很高，主战场在少数大实验室。

## 6. 前景

演示和落地会继续分开跑。

头条上的那条路会越来越像空间智能：模型看一段视频，就在内部维持一个可互动的场景。人推一下、机器人抓一下，它能回答接下来画面和受力会怎样。五年内，视频世界模型和机器人会在更多受控环境里接上。真正开放、长时间、还要负责安全的场合（手术、露天公路、家里的杂物）会慢得多。生成出来的影像现在常常看起来对，物体个数、接触关系、细小文字仍会悄悄出错。研究的尺子正在从像素好不好看，改成物理是否一致、动作是否跟手、错误会不会越滚越大。

另一条路安静，但雇用的人和赚到的钱都很多：在一个窄任务上做得可靠。缺陷检测、医学影像、遥感、屏幕成色、农田病虫害，标签贵、反光和遮挡多、错一档就要付出代价。这里的进展通常是把通用特征接到小数据上，把标签定义写死，把失败案例当成一等结果。基础模型会变成这里的零件——用来提特征、做初标、生成合成缺陷。最后负责打分的，仍常常是一个小而较真的模型。

对做事的人，技能的重心已经移动了。手工设计 SIFT 那种特征的时代过去了。现在更值钱的是：把一个模糊的视觉问题收成可标注、可度量的任务；知道何时该用现成的大模型，何时它会在反光和细裂纹上撒谎；以及把错误写清楚，而不是只报一个平均准确率。

视觉不会被做完。互联网照片上的常见物体识别，已经好到日常产品可以直接用。稀有外观、物理后果、长时间一致，以及「错了要负责」的判断，仍是开放问题。越往后，计算机视觉越像智能体的视觉皮层：和语言、动作、三维几何长在一起。窄而硬的感知任务会变成检验这些皮层到底有没有看懂的地方。

## 7. 和本课题的关系

屏幕损伤分级站在第 6 节的第二条路上。人眼看一张屏幕照片，说的是「伤得重不重」；模型要在已经知道这是手机或平板屏幕的前提下，给出有顺序的档次。这难在刻度，容易错在反光、污迹和细裂纹。

和上面几代工作的对应关系：

| 学科里的问题 | 本课题里对应什么 |
|--------------|------------------|
| 分类 | 默认输出：无 / 轻 / 中重。档次有顺序，见 `notes/papers/2020-cao-coral.md` |
| 检测或分割 | 可选前置：先框出或涂出伤痕，再分级。数据侧见 `notes/papers/2023-han-ssgd.md` |
| 自监督特征和基础模型 | 小数据上的起点，用来提特征或辅助初标 |
| 视觉语言模型 | 能说人话，刻度不稳，不直接当主结果 |
| 世界模型和机器人 | 本课题不做 |
