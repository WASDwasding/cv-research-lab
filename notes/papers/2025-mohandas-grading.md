# 翻新产线里的手机屏幕：先检测严重度，再合成成色档

Mohandas, Southern, Fitzpatrick, Hayes. *Deep learning enabled computer vision in remanufacturing and refurbishment applications: defect detection and grading for smart phones.* Journal of Remanufacturing, 15 (2025) 65–95. DOI:10.1007/s13243-024-00147-2.  
收到 2024-07-15，接收 2024-12-10，在线发表 2025-01-14。开放获取。

这篇笔记按原文的问题、两套数据、四类严重度、成色怎么由检测结果算出来、表里的数字和作者承认的边界来写。他们的图不下载，数字也不能写进我们的主表。

---

## 1. 他们要解决的问题

二手手机翻新时，人眼给屏幕定成色。班次长了，同一块伤会被标成不同档，后面的抛光次数和能不能卖都会跟着错。作者把这件事放进再制造流程里的「核心件检验」：退回来的手机先看屏幕，再决定拆件、抛光还是直接淘汰。

对象只限正面屏幕上的划痕和裂纹。后盖、边框不在这篇里。任务分两步：检测器框出每一处伤并给出严重度类别；整机成色不由网络直接输出，而由类别和个数按一张规则表算出来。

## 2. 标签怎么定义

他们自采，不是 SSGD。显微镜加漫射光，想压住屏幕反光。反光会把同一处伤照成两种样子，标注时就会分成两类。

数据有两版，原文 Table 3：

| 版本 | 手机数 | 图像数 | 分辨率 | 标签 |
|------|--------|--------|--------|------|
| 1，概念验证 | 24 | 106 | 1920×1080，只拍到屏幕大约六分之一 | 全部叫 scratch，单类检测 |
| 2 | 115 | 246 | 1920×1080，整块屏幕入画 | 四类严重度 |

版本 2 的四类在 Table 4。Class 1 是浅、可抛掉的划痕（低亮度、发灰）。Class 2 是更深的划痕，抛光也不容易去掉。Class 3 是发丝裂纹。Class 4 是大裂纹和碎边。

整机成色 A–D 在 Table 5，按「先淘汰最重的」：

- 只要有 Class 4，或有 Class 3，就是 D。
- 没有裂纹、但有 Class 2，是 C。
- 只剩 Class 1：个数 ≥ 10 是 B，少于 10 是 A。

所以成色看的是最重的一类，再加 Class 1 的个数。Class 1 再多也不会盖过一条裂纹。这和我们「整图取最重一处」同一方向，但他们是四类缺陷再合成四档成色，我们是无 / 轻 / 中重三档，而且裂纹无论长短都升到中重。

## 3. 方法在算什么

检测器在框和掩膜上训练：YOLOv7、YOLOv8 的 n 与 x、YOLO11 的 n 与 x、Mask R-CNN。成色没有单独一个分类头。推理先出各类检测个数，再套 Table 5。

Class 3、Class 4 张数少。他们用道路裂纹分割集先微调，再回到手机屏幕。原文写 Class 4 的精度因此提高了 0.44。增强用了 YOLO 自带的 mosaic、mixup、翻转、噪声、缩放、剪切、平移和裁切。

## 4. 表里的数字

摘要里的 70.4% 精度和 8 ms，对应 YOLOv8x 的推理速度和分割精度这句话，不是整机成色准确率。

Table 7 把检测准确率按 IoU 阈值 70% 来算。版本 2 的准确率是四类平均：

| | 图像数 | IoU（%） | Precision | Recall |
|--|--------|----------|-----------|--------|
| Mask R-CNN，版本 1 | 106 | 83.14 | 0.8 | 0.8 |
| Mask R-CNN，版本 2 | 246 | 73.43 | 0.7 | 0.68 |

YOLO 各变体的逐类数在原文 Table 9，类别之间差很大。Fig. 14 的精度–召回曲线里，Class 3 的精度和召回可以掉到 0.2 附近。作者把这归因于类不平衡，不是模型已经把发丝裂纹分稳。

这些数字都在他们自己的 246 张图上。不是 SSGD，也不是我们的测试划分。

## 5. 作者承认的边界

- 版本 1 只有屏幕的一小块，而且所有伤都叫 scratch。
- 屏幕反光会改变同一处伤的外观，光照角度一变，标注类别就变。
- 四类个数不均，裂纹类更少。
- 检测类别不等于成色档：一台机器有 Class 1 和 Class 2，只要再有一处 Class 4，整机仍是 D。
- 缺陷种类只讨论了划痕和裂纹。

## 6. 和本实验的关系

这篇是「屏幕严重度」最接近的公开工作，所以放进相关工作，不放进训练数据。用它说明两件事：整机档可以由最重的一处决定；反光会让同一条伤换档，这和我们失败案例里的反光当划痕是同一类问题。

不能搬的有三处。他们的 A–D 和 Class 1–4 不是我们的无 / 轻 / 中重。246 张私有图不能当 SSGD 的对照行。70.4% 和 Table 7 的 0.7 都不能写进我们的摘要。我们的主表仍只来自 SSGD 上的固定划分，真实小集只做掉点和 kappa。
