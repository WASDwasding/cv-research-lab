# cv-research-lab

用图像估计产品损伤程度。目标投正规 EI 会议或应用期刊。

## 这是什么

- 输入：一类产品的照片（先公开集）
- 输出：损伤等级（默认 3 档：无 / 轻 / 中重）
- 不是：物品分类、同物检索、从零训练大模型

## 目录

mentor_logs/       组会记录
