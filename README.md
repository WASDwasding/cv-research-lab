# cv-research-lab

本科论文项目：用图像估计产品损伤程度，目标投 **正规 EI**。

新开的 Cursor 窗口请先读 **[AGENTS.md](./AGENTS.md)**，再看 **[STATUS.md](./STATUS.md)**。把 **[OPENING.md](./OPENING.md)** 贴进新对话即可接手。

## 这是什么

- 输入：一类产品的照片（先公开集，后可加校园二手自拍）  
- 输出：损伤等级（默认 3 档：无 / 轻 / 中重）  
- 不是：认物品类别、同物检索、从零训大模型、数据库内核

申请、选校、课表不在本仓库。课设以后可提供商品图，现在不阻塞论文。

## 目录

```
AGENTS.md          给新 Agent 的完整背景（必读）
STATUS.md          当前进度，先看这个再动手
docs/              方向、投稿、实验设计
mentor_logs/       组会五分钟记录
experiments/       实验记录（硬件、命令、指标）
results/           数字与表
src/               训练/评测代码
data/              数据集（不进 git）
notes/papers/      读论文笔记
```
