# cv-research-lab

用图像估计手机和平板屏幕的损伤程度。目标投正规 EI 会议或应用期刊。投稿窗口是 2026-09-22～2026-10-22，按天计划见 `PLAN.md`。

## 这是什么

- 输入：已经知道是手机或平板的一张屏幕照片（先公开集 SSGD，再补真实拍摄）
- 输出：屏幕损伤等级（默认 3 档：无 / 轻 / 中重）
- 不是：认手机型号、同物检索、后盖或边框成色、从零训练大模型
