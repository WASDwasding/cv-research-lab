# 2026-09-28 第 0 周 M1：划分、多数类、ResNet-18

机器：联想 Y7000P，RTX 4060 Laptop，torch 2.6.0+cu124，torchvision 0.21.0+cu124。命令在仓库根目录：

```
python src/train_m1.py
```

## 样本

只用 COCO 标注里至少有一个 7 类框的图。整图档次取最重的一处，规则与 `experiments/label_protocol.md` 第 5 节相同。757 张没有任何这 7 类框的图不进入划分，也不叫做无。因此这一轮实际只有两档：轻 395 张，中重 1352 张，合计 1747 张。无的支持度是 0。

## 划分

种子 42，按档分层，比例 70/15/15。脚本用同一随机过程生成两次，路径和标签完全一致后才写出 `experiments/20260928_split_seed42.json`。

| 划分 | 轻 | 中重 | 合计 |
|------|----|------|------|
| train | 276 | 946 | 1222 |
| val | 59 | 203 | 262 |
| test | 60 | 203 | 263 |

两个微调种子共用这一份划分。种子只改变模型初始化和训练时的打乱顺序。

## 训练

ImageNet 预训练的 ResNet-18，最后一层换成 2 类。输入先缩到 224×224，训练时水平翻转，再用 ImageNet 的均值和方差。AdamW，学习率 0.0001，weight decay 0.0001，batch 32，固定 8 个 epoch。报的是第 8 个 epoch 的测试集，没有按验证集挑最好的一轮。

多数类基线：训练集里中重更多，所以测试集全部猜中重。

有序误差按协议编码计算：轻=1，中重=2。这两档只相差 1，所以只要预测错了就是差一档，差两档一定是 0。MAE 因此等于差一档的比例。
