# 3 档标注规则

> 日期：2026-09-22 写下三档；2026-09-23 把对象收成手机和平板的屏幕玻璃。  
> 适用：已经知道是手机或平板屏幕的单张图。不在这张图上判断型号，不评后盖、边框、摄像头。  
> 档是有序的：无 < 轻 < 中重。把「轻」判成「中重」只错一档；把「无」判成「中重」错两档。  
> 档的阈值不改：露底或开裂升档，最长划痕达到短边的 0.2 倍升档，累计面积达到 5% 升档。

公开集选定为 SSGD。映射按第 5 节，不另写一套档。

---

## 1. 先看什么，不看什么

看：屏幕上的划痕、裂纹、碎裂、缺角、漏光、膜层剥落、麻点、擦不掉的污迹。屏幕上的「露底」指裂穿、偏光层或膜层露出。  
不看：哪一款手机或平板、后盖、边框、摄像头、照片糊不糊、曝光是否讨喜。  
拍摄噪声、轻微压缩块、传感器彩噪，本身不算损伤。

一张图只给一个档，取该图上最重的一处损伤。

---

## 2. 三档可见特征

测量都相对这张图：短边记为 S，损伤区域按肉眼能圈住的外接面积占整图的比例估算。

| 档 | 代码 | 必须同时满足 | 三条可见特征 |
|----|------|----------------|--------------|
| 无 | 0 | 下面三条都成立 | 1. 表面连续，没有划痕、裂纹、凹坑、掉皮。2. 没有露底、没有变形。3. 孤立灰尘或脏点合计面积 < 1%，且不连成线。 |
| 轻 | 1 | 有损伤，但下面三条都成立 | 1. 伤得到，但是浅的：细划痕、浅磨损、浅凹，未露底、未开裂。2. 最长一条划痕 < 0.2S，累计损伤面积 < 5%。3. 损伤没有把零件断开，也没有明显变形。 |
| 中重 | 2 | 下面任意一条成立 | 1. 任一处露底、开裂、穿透、剥落，或能看出变形。2. 最长划痕 ≥ 0.2S，或累计损伤面积 ≥ 5%。3. 多处损伤里至少一处已经达到第 1 条或第 2 条。 |

「中」和「重」合成一档。论文里不把它们拆开。

## 3. 边界例

这些例子用来卡住容易吵起来的图。发生冲突时，以本节的结论为准。

| 编号 | 画面 | 判定 | 理由 |
|------|------|------|------|
| B1 | 一条头发丝一样的浅划痕，长度 0.1S，不露底 | 轻 | 有伤，但长度和面积都在轻档上限以下 |
| B2 | 同样很浅，但长度 0.25S，不露底 | 中重 | 长度已经 ≥ 0.2S，深度不能把它拉回轻档 |
| B3 | 划痕很短，但底材颜色或金属基体露出来 | 中重 | 露底单独升档，不看长度 |
| B4 | 指纹、水渍、可擦掉的灰尘，擦痕下表面还在 | 无 | 污渍不是损伤。前提是材质没有被磨掉 |
| B5 | 擦不掉的变色、烧蚀、锈已经吃进表面 | 先按面积和是否露底归入轻或中重 | 污渍只有在改变材质时才算损伤 |
| B6 | 画面里有一道反光亮线，换个角度就消失 | 无 | 反光不是伤。模型若把它判成划痕，记入失败案例，不改标签 |
| B7 | 小裂纹，长度 0.05S，但是裂开的 | 中重 | 开裂单独升档 |
| B8 | 两处浅划痕，每处都小于轻档上限，加起来面积仍 < 5%，都不露底 | 轻 | 取最重的一处；没有一处跨进中重 |
| B9 | 一处浅划痕加一处露底 | 中重 | 整图取最重的一处 |
| B10 | 背景里的桌子划痕、包装上的印刷线 | 不计入屏幕损伤 | 只评屏幕玻璃。背景被当成伤，是失败类型，不是标签 |
| B11 | 屏幕有裂纹，即使又短又细 | 中重 | 开裂单独升档，对应 SSGD 的 crack |
| B12 | 缺角、玻璃碎裂、裂成网 | 中重 | 碎裂，对应 SSGD 的 broken |
| B13 | 屏幕漏光，或保护膜、偏光层剥落 | 中重 | 层已经破，按露底处理。对应 light-leakage、broken-membrane |
| B14 | 可擦掉的指纹、油膜 | 无 | 沿用 B4。MSD 里的 oil 若擦得掉，不算损伤 |

---

## 4. 标的时候按这个顺序

1. 产品表面在不在画面里。不在就丢掉，不进三档。  
2. 有没有露底、开裂、穿透、剥落、变形。有则中重。  
3. 剩下的伤里，最长划痕是否 ≥ 0.2S，或累计面积是否 ≥ 5%。是则中重。  
4. 还有伤，但过不了第 2、3 步，则轻。  
5. 没有伤，指纹和水渍按 B4 处理，则无。

两人标同一张图时都用这五步。真实屏幕的双人一致率也用这五步，不另写一套口头标准。

---

## 5. SSGD 原标签怎么映射

下载后把各类张数填进张数列。理由用上面的阈值，不按「看起来严重」改档。

| 原标签 | 映射档 | 一句有序理由 |
|--------|--------|----------------|
| crack | 中重 | 开裂单独升档（B11） |
| broken | 中重 | 碎裂或缺块（B12） |
| light-leakage | 中重 | 漏光，层已透（B13） |
| broken-membrane | 中重 | 膜层剥落（B13） |
| scratch，最长 < 0.2S 且不裂穿 | 轻 | 有伤，但长度和面积都在轻档上限以下（B1） |
| scratch，最长 ≥ 0.2S | 中重 | 长度达标，深度不能把它拉回轻档（B2） |
| spot，累计面积 < 5% 且未开裂 | 轻 | 麻点，未开裂、未达面积上限 |
| spot，累计面积 ≥ 5% | 中重 | 面积达标 |
| blot，擦不掉且面积 < 5% | 轻 | 污迹改变了表面，但未达中重 |
| blot，擦得掉 | 无 | 指纹和油膜不是损伤（B4、B14） |
| 完好屏幕 | 无 | SSGD 没有这一类。张数写 0，不从别的缺陷改名凑出来 |

scratch 和 spot、blot 允许按阈值拆行，每一行都要有张数。整图仍取最重的一处。
