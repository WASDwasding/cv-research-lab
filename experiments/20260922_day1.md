# 2026-09-22 第 1 天过程

第 1 天要交三样东西：3 档规则、一次跑完的最小训练和验证准确率、能导出的论文壳 PDF。规则和贡献主张上午已经写入仓库。下午补上训练数字和 PDF。

## 1. 规则和贡献

`experiments/label_protocol.md` 把无 / 轻 / 中重写成可见特征。升档条件是露底、开裂、穿透、剥落、变形，或最长划痕达到短边的 0.2 倍，或累计损伤面积达到 5%。指纹和水渍不算伤。整图取最重的一处。

`paper/contributions.md` 的三条主张是分级定义、同一划分上的对照（含先定位再分级）、以及何时失效。

## 2. 环境

机器是联想 Y7000P。处理器 i7-14650HX。显卡 RTX 4060 Laptop，显存 8188 MiB，驱动 566.24。

Python 是 3.12.10，路径 `C:\Users\18701\AppData\Local\Programs\Python\Python312\python.exe`。系统里原来没有 PyTorch。直接 `pip install torch` 时，2.35 GB 的 CUDA 轮子在代理上停住，没有落盘。改用下面的地址把轮子下到临时目录再本地安装：

```
https://download.pytorch.org/whl/cu124/torch-2.6.0%2Bcu124-cp312-cp312-win_amd64.whl
```

安装完成后的检查命令：

```
python -c "import torch; print(torch.__version__, torch.cuda.is_available(), torch.cuda.get_device_name(0))"
```

输出是 `2.6.0+cu124 True NVIDIA GeForce RTX 4060 Laptop GPU`。当时没有 numpy，torch 打了一条初始化警告，不影响这次前向和反传。torchvision 没装上，公开索引在连接被重置后找不到 `0.21.0+cu124`。

## 3. 最小训练

脚本是 `src/env_check.py`。它先尝试 CIFAR-10，失败就改用本地合成的 3 档图：轻档在中间画一条亮线，中重档加一块高亮方块。合成图只用来证明 GPU 能训完。

第一次合成数据的张量形状对不齐，报错 `output with shape [3, 32, 32] doesn't match the broadcast shape [1, 3, 32, 32]`。把加性图案收成 `[32, 32]` 后再跑。

在仓库根目录执行：

```
python src/env_check.py --epochs 2 --train-n 4000 --val-n 1000
```

日志要点：

```
dataset synthetic-3grade classes 3
train 4000 val 1000 device cuda
epoch 1 train_loss 0.9969 val_acc 0.6390
epoch 2 train_loss 0.6397 val_acc 0.6370
elapsed_sec 1.0
```

记入环境检查的数字是第 2 轮验证准确率 **0.6370**。随机初始化的小卷积网络，两轮之后停在这个数，没有继续加轮。

## 4. 论文 PDF

`paper/main.tex` 是五节标题的 LaTeX 壳。本机没有 pdflatex。`paper/build_shell.py` 原先用 fontTools 裁黑体，裁中文全字库时进程停住，没有写出 PDF。改成用 Pillow 和 `C:\Windows\Fonts\simhei.ttf` 直接画页，再存成 PDF。

```
python paper/build_shell.py
```

得到 `paper/shell.pdf`，151419 字节，文件头是 `%PDF-`。页内有摘要、三条贡献和五节标题，没有填实验数字。
